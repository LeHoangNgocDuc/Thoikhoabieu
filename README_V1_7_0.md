# Smart TKB 1.7.0 — Bản hoàn thiện chỉnh sửa tiết chính khóa

Bản nâng cấp cho Smart TKB Nam Nha Trang (ngày 10/11/2026).

**Điểm mới:** chạm vào ô trùng chọn chính xác lớp; sửa, xóa, sao chép/dán tiết; phạm vi chỉ một tuần hoặc lặp đến ngày có TKB mới; lưu và xác minh trực tiếp trong Google Sheets; không ghi đè các phiên bản cũ và PPCT đã xác nhận.

**Hướng dẫn cài đặt:** đọc `HUONG_DAN_NANG_CAP_V1_7_0.md` trước khi cập nhật.

**Kiểm thử:** 82/82 bài kiểm thử Node.js đạt; quy trình giao diện desktop và điện thoại đã vượt qua kiểm thử giả lập.

**Lưu ý quan trọng:** cập nhật cả **GAS `gas/Code.gs`** và **GitHub/Vercel**. Chỉ thay GitHub hoặc chỉ lưu code Apps Script chưa đủ. Thay deployment hiện tại bằng **Phiên bản mới** qua bút chì để giữ `GAS_URL`.
